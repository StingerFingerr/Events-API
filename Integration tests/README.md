# Интеграционные тесты репозиториев

Для запуска нужен Docker с Linux-контейнерами. Запускать Docker Compose и создавать базу вручную не требуется:

```powershell
dotnet test "Integration tests/Integration tests.csproj"
```

Testcontainers автоматически запускает PostgreSQL `16-alpine` (как в `docker-compose.yml` приложения) на свободном порту и удаляет контейнер после завершения тестов. Строка подключения получается из контейнера; настройки базы приложения не используются.

Оба класса тестов входят в одну коллекцию xUnit и используют один контейнер. Тесты этой коллекции выполняются последовательно. Перед каждым тестом, включая каждый вариант `[Theory]`, база контейнера удаляется через `EnsureDeletedAsync()` и создаётся заново через `MigrateAsync()`. Каждый тест самостоятельно подготавливает данные; проверки сохранения выполняются через отдельный DbContext.

Покрыты все методы `EventRepository` и `BookingRepository`, все сочетания фильтров событий, границы дат, регистронезависимый поиск, сортировка, страницы и общее количество результатов. Дополнительно проверяются перечитывание изменённых и удалённых событий, выборка ожидающих бронирований, внешний ключ, каскадное удаление, совместное сохранение бронирования и занятого места и откат при ошибке вставки.

Для повторной проверки стабильности выполните команду запуска дважды. Для запуска всех тестов решения используйте `dotnet test` из корня проекта.
