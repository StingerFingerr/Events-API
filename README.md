# Events API

REST API для управления списком событий, построенное на платформе ASP.NET Core (.NET 10).

---

## Запуск приложения

### Шаг 1. Предварительные требования
Убедитесь, что у вас установлен **.NET SDK 10.0**.  
Проверить версию можно командой в терминале:
```bash
dotnet --version
```

### Шаг 2. Клонирование и переход в папку проекта
```bash
git clone <ссылка_на_ваш_репозиторий>
cd "Events API" 
```

### Шаг 3. Сборка и запуск приложения
Запустите команду сборки и старта проекта из папки, где находится файл решения (`.sln`):
```bash
dotnet run
```

---

## Как тестировать API (Документация)

После успешного запуска приложение будет доступно локально. Для проверки эндпоинтов настроена интерактивная документация:

* **Swagger UI:** Перейдите по адресу [https://localhost:5002/swagger](https://localhost:7193/swagger) *(или укажите ваш порт из launchSettings.json)*, чтобы отправлять запросы прямо из браузера.
* **OpenAPI Спецификация (JSON):** Сырая схема эндпоинтов доступна по адресу `https://localhost:5002/openapi/v1.json`.

## Реализованные эндпоинты (CRUD)

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| **GET** | `/api/events` | Получить список всех событий |
| **GET** | `/api/events/{id}` | Получить детальную информацию о событии по ID |
| **POST** | `/api/events` | Создать новое событие (Возвращает `201 Created`) |
| **PUT** | `/api/events/{id}` | Полное обновление (замена) события |
| **PATCH**| `/api/events/{id}` | Частичное обновление (только `Title`) |
| **DELETE**| `/api/events/{id}` | Удаление события (Возвращает `204 No Content`) |
